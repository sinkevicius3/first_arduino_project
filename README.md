# Arduino Uno Traffic Light & Pedestrian Crossing

A simple traffic light simulation with pedestrian crossing controls for Arduino Uno.

## Main features

* Traffic light control (red, yellow, green) 
* Pedestrian ligh control (red, green)
* Button to request a pedestrian crossing
* Piezo buzzer with warning sounds during pedestrian crossing
* 7-segment display countdown to show the next available time a pedestrian crossing could be requested
* Blinking lights to indicate state changes

For more details, see [description.pdf](description.pdf).
